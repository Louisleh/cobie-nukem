# Cobie Nukem quality readiness scorecard

This scorecard tracks the eight existing PRD milestones. PRD §1.5, the implementation plan and the buildout ledger remain authoritative. It is an editorial, evidence-backed readiness assessment on a 0–100 index, not percentage completion, probability of AAA quality, statistical confidence or a substitute for approval. There is no global average.

The frozen `readiness-v1` rubric has 40 dimensions. Unperformed or unsupported outcomes earn zero; valid partial component work earns only scoped credit. Critical gates cap the result, so strong tooling or art cannot average away a lifecycle failure. Human quality confidence is currently low; technical evidence confidence is generally medium. These are editorial labels, not confidence intervals.

## Frozen assessment anchors

- **0**: No applicable valid evidence, not performed, or failed target; record which, never infer product is bad from unknown. Plans/prompts/reports alone earn no delivered-outcome credit.
- **25**: Meaningful source/component/isolated technical contract or bounded authored pilot supported; human-only row requires actual limited named human check.
- **50**: Representative normal current-package behavior in declared pilot scope with source/observer limits; human-only row requires actual representative named review. Partial coverage is explicit.
- **75**: Frozen dimension target substantially proven in its entire declared scope, clean actual integration/appropriate ordinary controls and independent validation; unresolved blocker in that same target prevents 75. For narrow pipeline rows scope stays narrow.
- **100**: Every frozen dimension acceptance condition and applicable named human/physical/release approval met, independent evidence review and no unresolved critical defect in that scope. Means approved scoped target, not perfection or permanent safety.

Weighted subtotal = Σ(weight × dimension assessment) / 100. The index is the lowest applicable cap or subtotal, rounded **down** to the nearest five. Dimension values in v1 are only 0, 25, 50, 75 or 100. A finer dimension scale requires a new frozen rubric version.
